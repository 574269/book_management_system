# 簡易書籍管理系統

本專案為 1151 Scripting 程式語言期中作業，使用 Python 實作命令列版簡易書籍管理系統。

## 程式功能

1. **顯示全部書籍**：列出目前系統內所有書籍的編號、書名、作者、價格（含千分位）與借閱狀態。
2. **新增書籍**：依序輸入書籍編號（不可重複）、書名、作者與價格（大於 0 之整數），預設狀態為可借閱。
3. **查詢書籍**：依書名關鍵字進行不分英文大小寫的查詢。
4. **變更借閱狀態**：輸入完整書籍編號，在「可借閱」與「已借出」之間切換狀態。
5. **顯示最後 3 筆書籍與統計**：顯示串列最後 3 筆書籍，並計算總數、可借閱數、已借出數、價格合計與平均價格。
6. **匯出書籍資料**：將目前所有書籍資料匯出至 `output.json`。

## 專案結構

- `app.py`：主程式與選單迴圈
- `books.json`：初始書籍資料檔（UTF-8 編碼）
- `pkg/book_tools.py`：書籍讀寫、查詢、顯示與統計等自訂函式模組

## 執行方式

請確認專案根目錄下存在 `books.json`，並在終端機執行以下指令：

    python app.py

## 資料匯出方式

在執行程式時，於主選單輸入 `6`（匯出書籍資料），系統即會將目前記憶體中的所有書籍資料（包含新增與修改過借閱狀態的書籍）以 UTF-8 編碼寫入專案根目錄下的 `output.json` 檔案中。若離開系統前未執行功能 `6`，變更將不會保存。
